# Recursos Humanos — Grupo Metelmex

App web de RH (ausentismo, cumpleañeros, capacitación, servicio médico, revisión de nómina y Kpis semanal).

- Se publica con GitHub Pages desde la rama `main`.
- Los datos viven en un Google Sheet privado y se leen a través de Apps Script con inicio de sesión; este repositorio solo contiene la parte visual.
- Nunca subir aquí: catálogos de empleados, Excel con datos, código de Apps Script, claves ni respaldos (ver `.gitignore`).
